# Mutta — គេហទំព័រ Portfolio សម្រាប់ Web Developer ទំនើប 🚀
> **Modern Web Developer Portfolio Profile**

គេហទំព័រផ្ទាល់ខ្លួន (Personal Portfolio) កម្រិតខ្ពស់ រចនាឡើងយ៉ាងផ្ចិតផ្ចង់ និងទាក់ទាញបំផុតសម្រាប់ Developer ឈ្មោះ **Mutta** (Full-Stack Web Developer)។ គម្រោងនេះត្រូវបានបង្កើតឡើងដោយប្រើប្រាស់បច្ចេកវិទ្យាទំនើប **PHP 8+**, **Tailwind CSS**, ស្ទីលរចនាបែប **Glassmorphism**, ការផ្លាស់ប្តូរ Theme (Dark/Light Mode), និងប្រព័ន្ធទំនាក់ទំនង (Contact Form) ដែលដំណើរការជាមួយ AJAX និងកត់ត្រាសារទុកក្នុង JSON ដោយស្វ័យប្រវត្តិ។

## ✨ លក្ខណៈពិសេសចម្បងៗ (Key Features)

### 🎨 1. ការរចនា និងចំណុចប្រទាក់អ្នកប្រើ (Modern UI/UX)
- **Dark Mode ជាលំនាំដើម (Default)** ជាមួយពន្លឺ radial mesh gradients ស្រស់ស្អាតបែប futuristic។
- **មុខងារប្តូរ Theme (Light / Dark Mode Switch)**៖ ដំណើរការលឿន មិនរអាក់រអួល និងចងចាំជម្រើសរបស់អ្នកប្រើប្រាស់តាមរយៈ `localStorage` ដោយ sync រវាងកុំព្យូទ័រ (Desktop) និងទូរស័ព្ទ (Mobile)។
- **Glassmorphism Panels**៖ ប្រើប្រាស់ `backdrop-filter: blur(...)` បង្កើតផ្ទាំងកញ្ចក់ថ្លាទំនើប និងមាន Hover Effects ភ្លឺរលោងពេលដាក់ Mouse ពីលើ។
- **Mac-style Code Terminal**៖ ផ្ទាំង Terminal ក្លែងធ្វើកូដបែប macOS ជាមួយ Tabs ចុចប្តូរបាន (`Mutta.php`, `stack.json`, `run.sh`)។
- **ពុម្ពអក្សរស្អាតច្បាស់**៖ ប្រើប្រាស់ **Plus Jakarta Sans** សម្រាប់អត្ថបទ និង **JetBrains Mono** សម្រាប់កូដ។

### 📱 2. បទពិសោធន៍លើទូរស័ព្ទដៃ (Mobile-First Experience)
- **Mobile Bottom Navigation Dock**៖ របារ Navigation អណ្តែតខាងក្រោមអេក្រង់ទូរស័ព្ទដៃស្ទីល iOS (`Home`, `About`, `Skills`, `Projects`, `Contact`) មាន Indicator រលោង និងប្រាប់ទីតាំងទំព័របច្ចុប្បន្ន (Active Tab Detection)។
- **Mobile Drawer Navigation**៖ ម៉ឺនុយទូរស័ព្ទរុញចេញចូលយ៉ាងរលូន (Responsive Drawer) គាំទ្រទាំង Dark និង Light Theme។

### ⚡ 3. ផ្នែកសំខាន់ៗក្នុងគេហទំព័រ (Interactive Sections)
- **Hero Section**៖ បង្ហាញ Badge ស្ថានភាពការងារ (Availability Badge), ព័ត៌មានសង្ខេប, ប៊ូតុង Call-to-Action (CTA), និងស្ថិតិរស់រវើក។
- **Live Statistics Banner**៖ លេខរាប់ស្ថិតិបែប Animation (បទពិសោធន៍ការងារ, ចំនួនគម្រោង, ការពេញចិត្តរបស់អតិថិជន, APIs)។
- **About Me**៖ ប្រវត្តិរូបផ្ទាល់ខ្លួន ដំណើរជីវិតការងារ និងគោលការណ៍វិស្វកម្មស្នូលទាំង ៤ (Architecture, Clean Code, Performance, Reliability)។
- **Skills Matrix (ជំនាញបច្ចេកវិទ្យា)**៖ ចែកចេញតាមជំពូក (*Frontend*, *Backend*, *Databases*, *DevOps*) ជាមួយរបារ Progress Bar បង្ហាញកម្រិតជំនាញ និងប៊ូតុង Filter។
- **Featured Projects (គម្រោងស្នាដៃ)**៖ បង្ហាញគម្រោងនានា អាច Filter តាមប្រភេទ (*Full-Stack*, *Frontend*, *Backend*), បង្ហាញ Mockup ពណ៌ Gradient និងមានផ្ទាំង **Project Details Modal** លោតចេញមកបង្ហាញព័ត៌មានលម្អិត។
- **Services & Solutions (សេវាកម្ម)**៖ រាយនាមសេវាកម្មដែលផ្តល់ជូនអតិថិជន។
- **Career Roadmap (ប្រវត្តិការងារ & ការសិក្សា)**៖ បង្ហាញ Timeline បទពិសោធន៍ការងារ និងការបណ្តុះបណ្តាល។
- **Client Endorsements (មតិអតិថិជន)**៖ កាតបង្ហាញមតិកោតសរសើរពីអតិថិជន និងដៃគូការងារ។

### 📬 4. ប្រព័ន្ធផ្ញើសារទំនាក់ទំនង (Functional Contact Form)
- **ដំណើរការទ្វេ (Dual-Handling)**៖ គាំទ្រការផ្ញើបែប **Async AJAX** (មិនបាច់ Reload ទំព័រ) ជាមួយសារជូនដំណឹង Toast Notification និងមាន Fallback ទៅកាន់ PHP POST ធម្មតា។
- **ការរក្សាទុកសារស្វ័យប្រវត្តិ**៖ រក្សាទុកសារចូលក្នុងឯកសារ `storage/messages.json` ជាទម្រង់ JSON ងាយស្រួលគ្រប់គ្រង។
- **ប៊ូតុង Copy Email**៖ ចុចតែម្តងដើម្បីចម្លងអ៊ីមែល ជាមួយ Tooltip បង្ហាញភ្លាមៗ។

## 🚀 របៀបដំឡើង និងដំណើរការលើកុំព្យូទ័រ (How to Run Locally)

គម្រោងនេះដំណើរការលើ **PHP 8.0 ឬខ្ពស់ជាងនេះ** (PHP 8.1+ គឺល្អបំផុត)។ អ្នកអាចដំណើរការតាមជម្រើសពីរខាងក្រោម៖

### ជម្រើសទី ១៖ ដំណើរការតាមរយៈ Laragon (វិធីសាស្ត្រណែនាំ ⭐)
1. បើកផ្ទាំងគ្រប់គ្រង **Laragon**។
2. ចុចប៊ូតុង **Start All** (ដើម្បីដំណើរការ Apache និង MySQL)។
3. បើក Browser (Chrome, Edge, Firefox...) រួចចូលទៅកាន់អាសយដ្ឋាន៖
   ```text
   http://localhost/WebDevelopment
   ```
   *(ឬ `http://webdevelopment.test` ប្រសិនបើអ្នកបានបើកដំណើរការមុខងារ Auto Virtual Hosts ក្នុង Laragon)*

### ជម្រើសទី ២៖ ដំណើរការតាមរយៈ PHP Built-in Server
បើក Terminal ឬ PowerShell ក្នុងថត `C:\laragon\www\WebDevelopment` រួចវាយពាក្យបញ្ជា៖
```bash
# ប្រសិនបើប្រើ PHP របស់ Laragon:
C:\laragon\bin\php\php-8.1.10-Win32-vs16-x64\php.exe -S localhost:8000

# ឬប្រសិនបើអ្នកបាន set PHP ក្នុង System Environment Variables រួចហើយ៖
php -S localhost:8000
```
បន្ទាប់មកបើក Browser ហើយចូលទៅកាន់៖ [http://localhost:8000](http://localhost:8000)

## 🛠️ របៀបកែសម្រួលទិន្នន័យផ្ទាល់ខ្លួន (How to Customize)

ទិន្នន័យទាំងអស់ត្រូវបានរៀបចំជា Array ក្នុងភាសា PHP យ៉ាងមានរបៀបរៀបរយនៅផ្នែកខាងលើនៃឯកសារ [index.php](file:///c:/laragon/www/WebDevelopment/index.php)។ អ្នកអភិវឌ្ឍន៍ (Developer) អាចកែសម្រួលបានយ៉ាងងាយស្រួលដោយមិនបាច់ប៉ះពាល់ដល់កូដ HTML ស្មុគស្មាញឡើយ៖

1. **ព័ត៌មានផ្ទាល់ខ្លួន (Personal Information)**៖
   - កែសម្រួលក្នុង Array `$profile` ដូចជា៖ ឈ្មោះ (`name`), តួនាទី (`title`), ជីវប្រវត្តិសង្ខេប (`bio`), ទីតាំង (`location`), អ៊ីមែល (`email`), លេខទូរស័ព្ទ (`phone`), និងតំណភ្ជាប់បណ្តាញសង្គម (`github`, `linkedin`, `twitter`, `discord`)។
2. **ជំនាញបច្ចេកវិទ្យា (Skills Matrix)**៖
   - បន្ថែម លុប ឬកែប្រែបញ្ជីជំនាញក្នុង Array `$skills` (កំណត់ឈ្មោះ, ប្រភេទ `category`, កម្រិតភាគរយ `progress`, និង Icon)។
3. **គម្រោងស្នាដៃ (Projects Showcase)**៖
   - បន្ថែមគម្រោងថ្មីៗ ឬកែសម្រួលគម្រោងដែលមានស្រាប់ក្នុង Array `$projects` (ចំណងជើង, ការពិពណ៌នា, បច្ចេកវិទ្យាដែលប្រើប្រាស់, តំណ Demo ឬ GitHub Repo)។
4. **ប្រវត្តិការងារ និងការអប់រំ (Career Roadmap / Timeline)**៖
   - កែសម្រួលតួនាទី កាលបរិច្ឆេទ និងស្ថាប័នក្នុង Array `$timeline`។
5. **សេវាកម្មដែលផ្តល់ជូន (Services)**៖
   - កែប្រែប្រភេទសេវាកម្ម និងលក្ខណៈពិសេសក្នុង Array `$services`។

## 📬 ប្រព័ន្ធប្រអប់សារទំនាក់ទំនង (Contact Form Storage)

រាល់ពេលដែលភ្ញៀវចូលមើលគេហទំព័រ ហើយបំពេញទម្រង់ផ្ញើសារ (Contact Form) ទិន្នន័យសារនឹងត្រូវបញ្ជូន និងកត់ត្រាទុកដោយស្វ័យប្រវត្តិក្នងឯកសារ៖
- `storage/messages.json`

ទិន្នន័យក្នុងសារនីមួយៗរួមមាន៖
- **`id`** ៖ លេខកូដសម្គាល់សារ (Submission ID)
- **`name`** ៖ ឈ្មោះអ្នកផ្ញើ
- **`email`** ៖ អាសយដ្ឋានអ៊ីមែលរបស់អ្នកផ្ញើ
- **`subject`** ៖ ប្រធានបទនៃសារ
- **`service`** ៖ ប្រភេទសេវាកម្មដែលអ្នកផ្ញើចាប់អារម្មណ៍
- **`message`** ៖ ខ្លឹមសារលម្អិតនៃសារ
- **`ip`** ៖ អាសយដ្ឋាន IP របស់អ្នកផ្ញើ
- **`created_at`** ៖ កាលបរិច្ឆេទ និងម៉ោងដែលបានផ្ញើ

> [!NOTE]
> ប្រសិនបើថត `storage/` មិនទាន់មាន នោះកូដ PHP ក្នុង `index.php` នឹងបង្កើតថតនេះ និងឯកសារ `messages.json` ដោយស្វ័យប្រវត្តិ។
